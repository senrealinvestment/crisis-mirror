# Session templates

## A. Full scaffold (20–30 min)

1. Level 0 map + core claim restatement (3 min)
2. Level 1: 3–5 chunks with micro-retrieval (10–12 min)
3. Level 2: one comparison table + 2 why-questions (5 min)
4. Level 3: 6 mixed questions, re-queue misses (5–7 min)
5. Level 4: 3-min teach-back + rubric (5 min)
6. Level 5: exit ticket + spaced schedule (2 min)

## B. Drill only (10–15 min)

1. Cold free-recall (90 seconds)
2. 8 interleaved questions
3. Feedback protocol on misses
4. Re-test misses in new form
5. Update spaced cards for misses only

## C. Teach-prep (for rounds / lecture)

1. Force learner outline (no notes): claim → 3 points → caveat → pitfall
2. Fill gaps with minimal scaffold card
3. Learner re-outlines from memory
4. Deliver 5-minute teach-back
5. Compress to 60-second “elevator teach”
6. Schedule +1 day teach-back again

## D. Weak-spot clinic

1. List last misses (from prior footer)
2. For each miss: 60s re-explain → new example → new question → re-try
3. Mixed set of only former misses + 2 former strengths (prevent overfit)
4. Footer with new schedule

## E. Career seal check (cold)

No notes. No warm-up content dump.

1. Free recall dump (3 min)
2. Two novel cases
3. Full teach-back
4. Rubric
5. If pass: mark sealed + set +3 month maintenance card
6. If fail: return to weak-spot clinic, not full re-lecture

## Exit ticket bank patterns

- “State the core claim.”
- “Name three must-know supports.”
- “What is the hard stop / exception?”
- “Compare A vs B in one sentence.”
- “Teach this in 30 seconds.”
