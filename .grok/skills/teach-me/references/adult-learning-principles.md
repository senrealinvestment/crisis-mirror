# Adult learning principles (operational)

Use these as design constraints, not as a lecture to the learner.

## Evidence-aligned mechanisms (what actually sticks)

| Principle | What to do in teach-me | What to avoid |
|-----------|------------------------|---------------|
| **Retrieval practice** | Ask before re-showing notes | Re-reading as the main activity |
| **Spaced practice** | Schedule +1d / +3d / +1w / +1m / +3m | Cram-once “we’re done” |
| **Desirable difficulties** | Free recall, interleaving, generation | Only easy recognition quizzes |
| **Scaffolding → fading** | Supports first, then remove | Permanent hand-holding or sink-or-swim |
| **Elaboration** | Why/how, analogies, links | Isolated fact lists |
| **Dual coding** | Brief table + short prose + one vignette | Walls of text only |
| **Feedback** | Immediate, specific, re-test | Delayed vague praise |
| **Generation effect** | Learner produces explanations | Only consuming model output |
| **Mastery / teach-back** | Feynman gate before “done” | “Covered it” = learned it |
| **Adult relevance** | Tie to practice, career teaching duty | Abstract trivia without use-case |

## Andragogy cues (Knowles-aligned, practical)

Adults learn better when:

1. **Purpose is clear** — state the career/teaching use in Level 0.
2. **Experience is used** — ask what they already know; diagnose first.
3. **Autonomy is respected** — offer format choice (full / drill / teach-prep).
4. **Problem-centered** — cases and decisions over pure taxonomy.
5. **Immediate application** — every chunk ends in a micro-decision or explain-aloud.

## Cognitive load (keep working memory safe)

- Max **3–7 chunks** per topic module.
- One new schema per mini-cycle: explain → example → retrieve.
- When introducing a comparison (A vs B), freeze other new content.
- Offload to a **minimal scaffold card**, then force retrieval with card closed.

## Error culture

- Errors are data, not failure.
- Tag the misconception; re-test in a new form.
- Never advance past a critical safety error (e.g., contraindication miss in clinical topics).

## Career-long teaching standard

Knowledge is “sealed” only when the learner can:

1. Free-recall the core claim and must-know bullets cold.
2. Apply to a novel case.
3. Teach a peer in ≤5 minutes with correct caveats.
4. Pass a delayed review (+1 week minimum) without re-study of the full notes.
