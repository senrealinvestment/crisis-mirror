# Teach-back rubric (Level 4 gate)

Score each domain 0–2. **Critical fail** if any safety/exception domain is 0 on a clinical topic.

## Domains

### 1. Core claim (0–2)
- 0: Missing, wrong, or vague
- 1: Mostly right but incomplete
- 2: Accurate one-liner a peer could reuse

### 2. Structure (0–2)
- 0: Stream of consciousness
- 1: Some order, missing map
- 2: Clear beginning (claim) → supports → caveats → pitfall

### 3. Key supports (0–2)
- 0: No evidence/mechanism/steps
- 1: Partial supports
- 2: 3 solid supports (numbers/steps only if actually known)

### 4. Contrast / discrimination (0–2)
- 0: No comparison or wrong contrast
- 1: Superficial contrast
- 2: Clear when A vs B (or rule vs exception)

### 5. Exceptions / hard stops (0–2) — **critical in clinical topics**
- 0: Omits major contraindication or hard stop
- 1: Mentions vaguely
- 2: States hard stops correctly and when to choose alternative

### 6. Common pitfall (0–2)
- 0: None
- 1: Generic pitfall
- 2: High-yield real pitfall (e.g., underdosing roc, ignoring duration)

### 7. Teaching clarity (0–2)
- 0: Could not teach a junior
- 1: Understandable but dense
- 2: Rounds-ready 30–60s version exists inside the teach-back

## Pass thresholds

| Goal | Pass rule |
|------|-----------|
| Basic recall | Total ≥ 8/14, no critical fail |
| Apply in practice | Total ≥ 10/14, exceptions = 2 if clinical |
| Career teach seal | Total ≥ 12/14, exceptions = 2, and delayed review later |

## Coach response after teach-back

1. Show scores in a small table.
2. Quote one strong line they said (reinforce).
3. Name the highest-leverage miss.
4. One micro-drill (new form) on that miss.
5. Update session footer career gate status.
