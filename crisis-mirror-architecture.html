Crisis Mirror Architecture

Smart glasses ambient AI — cognitive companion for clinical medicine with real-time cue + feedback

Sense

  • • POV video ambient context
  • • Continuous / gated audio listen
  • • IMU / tap as optional trigger
  • • Phone or on-device pre-filter

Reason + Cue

  • • OpenEvidence-class retrieval + LLM
  • • Cognitive-forcing prompt (not autopilot)
  • • Multimodal cue: tone / haptic / HUD text
  • • Safety gate: advisory, no orders

Reinforce

  • • Post-event: was cue helpful?
  • • Post-event: was cue accurate?
  • • Cost + latency logged per cue
  • • Feeds model / policy update offline

Clinical constraints

  • • PHI minimization / BAA path
  • • Discrete cues (ICU optics + noise)
  • • Sim lab first, then limited bedside
  • • Human remains decision-maker
